# EECS 281 Projects

This repository contains 281 coursework for 26 Fall and is shared as a reference
for other students taking this course in University of Michigan, Ann Arbor.
Go Blue! :)

## Projects

- **Project 0:** Command-line parsing, vector usage, and input processing.
- **Project 1:** A treasure hunt program using stack- and queue-based search.
- **Project 2:** A stock market simulation and several priority queue
  implementations.
- **Project 3:** Log manager for timestamp, category, and
  keyword searches with an editable excerpt list.
- **Project 4:** Incoming.
